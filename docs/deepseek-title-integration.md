# DeepSeek 标题生成接入

标题生成独立调用 DeepSeek，系统提示词完整保存在 `apps/server/src/packaging/titles.ts`，使用用户提供的凤凰网科技编辑提示词。翻译、高光分析和字幕校对继续使用现有模型。

## 行为

- 每条切片生成新闻热点、冲突悬念、犀利观点、数据冲击（无数据则行业趋势）、深度洞察五个角度，推荐其中一个并提供理由。
- 每个候选引用切片原句 ID，服务端检查引用、数量、角度、重复及推荐索引；结构不合法自动修复一次。
- 封面与视频内部共用标题文字，保留各自排版样式。手工修改和自然语言修改同步两处。
- 保留历史三组候选及手工锁定内容；旧成片不主动重生成。用户重新生成或选择、修改标题后应用共用文本。
- 不因提示词包含“热点”而自行编造联网验证。未提供热点证据时不得宣称已核实近期热点。

## 配置

在项目根目录本地 `.env` 设置 `DEEPSEEK_API_KEY`。可选 `DEEPSEEK_BASE_URL`（默认 https://api.deepseek.com）和 `DEEPSEEK_MODEL`（默认 deepseek-flash）。密钥只在服务端使用，不写入前端。

缺失配置时返回明确错误，不用其他模型冒充 DeepSeek。配置后按应用环境重启服务，在成片确认页点击生成标题。

## 验证

已通过本地 HTTP 协议测试、包装 API 闭环、真实自动套框渲染测试、前端生产构建和服务端类型检查。测试使用模拟模型响应，验证接口与流程，不代表真实模型内容质量。当前未配置 DeepSeek 密钥，真实调用和标题质量待配置后验收。
