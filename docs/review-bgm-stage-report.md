# 第⑤步成片确认：AI 配乐与轨道编辑

## 已接入

- 确认套框后的逐片段音乐分析与默认应用：DeepSeek 结合片段逐字稿、频道、文本情绪、语速统计及保留段频率，返回真实曲库内3–5个候选及理由。适合配乐时选择第一名，不适合则默认关闭。缺少音乐设置的片段自动生成，手工选曲和关闭不被覆盖。
- BGM 面板支持真实音频试听、替换、关闭、手动上传，显示音乐来源和授权说明。支持 MP3/WAV/M4A/AAC/OGG/FLAC，限制50MB并用 ffprobe 验证真实音轨。上传的 BPM 未检测时明确显示未知。
- 音量、音乐播放起点、片内应用范围、淡入淡出、Audio Ducking。音乐不足循环；FFmpeg 对音乐做响度规范化，以原声驱动 sidechaincompress 后混音，保留清晰人声并限制混音峰值。
- 浏览器参数预览使用实际视频原声分析音乐动态音量，调整增益无需重新创建音频；实际成片预览和导出使用 FFmpeg 混音。浏览器实时预览与最终响度规范化不是采样级等同，成片以实际渲染为准。
- 标题、字幕、视频、BGM 轨道：标题显示区间拖动/裁剪；字幕显示范围及整体时间偏移；视频两端裁剪调用现有编辑接口，同步原声；BGM 区间整体拖动、两端裁剪。修改使用原有保存和更新预览流程。
- 视频首帧继续为封面，封面文字和视频标题共用，预览和导出跟随上传包框原始比例。其他工作流页面未改。

## 音乐素材与模型

当前没有外部授权音乐库。内置三首为项目代码本地合成的无歌词音乐，文件真实生成可播放，界面明确标为本地合成，不冒充商业音乐库或外部授权。可上传用户自己的音乐。

推荐默认复用 DeepSeek 配置；可通过 MUSIC_API_KEY / MUSIC_BASE_URL / MUSIC_MODEL 独立配置。原千问通道真实测试返回 Arrearage，因此音乐分析独立使用已验证的 DeepSeek，不改翻译及高光模型。

情绪根据文本判断；语速和剪辑频率基于逐字稿及保留段统计，没有声称完成声学情绪检测、实际逐镜头节奏识别或上传音乐 BPM 检测。

## 验证

- 84项测试通过；前端生产构建、服务端类型检查通过。
- 真实 FFmpeg 测试：循环、淡入淡出、无声视频配乐、时长、人声避让；分离配乐频段测量验证 ducking 时配乐降低超过3dB。
- 音乐API测试：真实合成文件、模型候选引用、缓存、错误文件拒绝、真实音乐上传和参数范围校验。

- 浏览器连接不可用，拖拽和实时试听交互尚未实机验收。当前4条启动实际混音预览生成。
