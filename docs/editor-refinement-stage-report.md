# 二次剪辑：字幕细化与模型助手

本轮实现用户提出的三项调整。「文稿字幕要呈现双英文字幕」按上下文理解为中英双语文稿，保留两种语言分别编辑。

- 默认字幕由原48缩小到32（以1080宽画布为口径），英文约为中文的72%；保留透明背景和15px黑描边。旧默认包装在进入编辑器准备字幕时升级，新手工字号仍可通过助手或后续文字面板调整。
- 中文按句末/分句标点及短句长度分屏，每屏更短；双语分屏对应拆分英文，避免同一整句英文在多个中文屏上重复。
- 显示/烧录时移除每行结尾的标点，保留句内标点、小数及原始文字。分屏时间为原句范围内估算，不宣称词级音频对齐。
- 左侧文稿卡片同时显示英文原文和中文译文，两种文字可分别修改；中文修改标为手工锁定，英文改动后需要重新核对译文。原ASR逐字稿不覆盖。
- AI剪辑助手改用既有千问模型规划操作，支持起止点调整、明确删除句子音画、修改中/英文字幕、选择语种、字幕字号/颜色、封面/正文标题及撤销/重做。不再依赖固定正则解析自然语言。
- 模型只返回白名单结构，服务器再做时间范围、句子ID、颜色/字号及revision校验。一次请求的多步编辑在事务中执行，任一步失败全部回滚；每步仍沿用原有历史快照，可逐步撤销。
- 不支持的BGM/人物切换等请求或有歧义指令会解释，不冒充执行。模型处理期间其他页面已修改片段则返回409，不覆盖更新。
