# 一键套框与完整包装交付

日期：2026-11-16。范围：用户点击二次剪辑页「套框确认」后，自动安排本次所选片段的封面、标题、字幕、品牌包框和真实成片预览。原有模板图片、Logo、原声和未选片段保留。

## 工作流

点击套框确认 → 后台准备本批次包装 → 三组标题配对生成并默认应用一组 → 复用/补齐字幕 → 抽取原比例封面帧 → 按包框窗口安排文字 → 串行生成实际视频预览及独立封面 → 自动进入成片审核。

- 已有候选及有效译文可复用，手工标题与字幕锁定继续保留。
- 本批次以 activeClipIds 为准。生成期间改变本次选择或编辑版本会明确失败，避免将旧结果套到新编辑。
- 重复点击进行中的套框任务不会重复入队。重启中断显示可重试，不假装完成。
- 旧任务尚未确认频道/包框时先在品牌面板确认；确认后自动启动包装。
- 审核页首先显示生成进度，完成后默认播放已保存版本的实际预览；用户可再调文字和画面。失败显示具体原因，可重试，不把未完成结果当成片。

## 模板适配

读取现有透明包框的封闭窗口，分别识别封面和正文。找不到封闭窗口时沿用正文已配置区域，封面使用参考布局的相对区域；不会生成或替换品牌图片。

- 封面标题放在封面画面及底部署名条下方，白色粗体居中，最多三行；初始字号按1080画布约64，过长则逐步适配，不静默截字。
- 正文标题放在窗口上部并避开顶部Logo，初始字号按1080画布约52；字幕放画面下部，保留此前语种、32号小字幕及透明背景/黑描边偏好。
- 封面、正文使用不同窗口和文字布局；自动布局保存在片段包装中，不改模板库或项目的原品牌快照。已有自动布局后重试保留微调。
- 画面采用 contain 等比例完整放入框内，默认缩放1、偏移0；比例不一致时留边，不用铺满裁切，也不横纵拉伸。封面同样按原比例放入封面窗口。
- 这是保持内容比例的缩放适配，输出编码仍会按选定分辨率重新采样，不承诺像素完全不变。横屏源片不能在“不裁切、不拉伸”的同时铺满竖框。
- 品牌底图先合成，文字在其上方绘制，避免原包框不透明装饰遮住封面标题。
- YUV视频窗口统一到偶数像素，处理720P缩放后产生奇数尺寸的留边错误。

## 验证与实际预览

- 自动套框闭环测试使用真实视频与FFmpeg，覆盖窗口识别、三组标题、字幕复用、封面抽帧、音轨、进行中去重、本批次隔离及原品牌图片不改。
- 画面边缘像素测试验证：横视频放入竖框后两侧边缘仍在，留边为黑色；封面图片未被拉伸。另验证不透明包框不会遮住其上方的文字。
- 使用既有真实34秒英文片段的隔离副本试跑，读取原模板、保留原音轨，产出真实成片和封面；没有覆盖原项目。实际发现并修复了奇数尺寸导致的FFmpeg留边失败，以及封面底部装饰遮字问题。局部图片改为读取本地文件内容解码，避免本地文件名被当作URL解析。

## 边界

没有授权音乐库，因此不自动添加BGM，继续保留原声。不自动生成外部B-roll或人物身份，也不把翻译文本复核当作原声/事实已核验。必要疑点仍需用户审核后再正式导出。
