# AI 自动剪辑与人工二次编辑：第一阶段交付报告

日期：2026-11-15。范围：编辑底座与频道品牌。状态：代码与自动化验证完成，等待用户页面试用确认；第 2 阶段未启动。

## 1. 已实现

| 模块 | 实际行为 |
|---|---|
| 统一编辑计划 | EditPlan v1 使用毫秒整数保存多段源视频保留区间；成片时间从 0 连续累计，所有片段按源视频顺序排列、不重叠，至少保留 1 秒 |
| 时间映射 | 统一 TimeMap 转换源片和成片时间；字幕与 B-roll 随内部删除重新映射，素材入点保留原始偏移；输出时长不再等于源片起止点的差 |
| 编辑交互 | 保留原起止点裁剪，新增「删除本句音画」、保留区间展示及重做；字幕修改修复了失焦不保存的问题 |
| 编辑历史 | 每次编辑保存完整内容快照；撤销/重做恢复字幕、素材、构图、封面等状态，独立保留审计记录；新编辑清空重做栈；revision 检查返回 409，避免旧页面覆盖新操作 |
| 四频道 | 科技、AI、机器人、财经具有独立受众、编辑目标和受保护术语默认配置；频道目标传入现有高光推荐 profile，无新增模型调用链 |
| 品牌绑定 | 新任务集中确认频道、封面与正文包框；新模板可标记适用频道，专属模板优先推荐，通用模板可以明确确认使用；禁止跨频道套用专属模板 |
| 模板版本 | 模板修改递增版本，任务保留模板完整快照；修改或删除模板库条目不会悄悄改变已绑定任务；品牌页可明确更换并应用到任务全部切片 |
| 构图与字幕 | 缩放/位移作用于固定视频窗口内部；包框窗口不跟人物移动；渲染字幕按模板安全区排版，超出时明确报错 |
| 真实渲染 | FFmpeg 同步 trim/atrim、concat 音画，重新映射字幕和素材；替换画面保留同期声；首屏封面与正文分别使用对应包框；封面文件包含标题及封面包框 |
| 成片预览 | 品牌页保存后创建 720P 代理任务；使用与正式导出同一个 renderClip 和计划快照；预览显示保存版本，修改后需重新生成。原片快速播放/页面示意图不冒充已渲染预览 |
| 任务状态 | 单进程串行渲染，状态 queued/rendering/completed/failed；任务冻结剪辑、模板、版本；只有失败任务可以重试；重试沿用原快照；新任务用于导出新编辑结果 |
| 重启处理 | 排队项恢复，在途项明确失败可重试；运行标识隔离旧回调，各次渲染使用独立产物文件名 |
| 数据存储 | bun:sqlite、WAL、事务、一次性 JSON 迁移及原件备份；数据库、旧 JSON 和备份不可通过 `/files` 下载，仅媒体目录开放 |

当前四频道规则是项目的可调整初始配置，不代表已取得凤凰网各频道正式品牌规范。没有伪造四套频道模板：现有「知识区竖屏包框」作为通用模板保留。

新增测试覆盖：

1. JSON 原件备份、ID/路径保持、重启不重复导入、跨连接可见、事务回滚；损坏 JSON 拒绝迁移，修复后可重试。
2. 源片/成片边界映射、跨删除区间的字幕与素材映射、完整撤销/重做、版本冲突、批量事务回滚、频道不匹配与模板快照隔离。
3. **真实 FFmpeg**：红/绿/蓝三段视频删除中间段，逐帧采样验证画面；440/660/880Hz 三段音频同步去中段，采样验证音频；成片时长误差小于 150ms；人物缩放不侵入窗口外；无音轨输入仍可导出。

5. **真实 API→SQLite→FFmpeg→文件**：代理/正式输出均使用旧冻结计划，排队后修改片段和模板不污染旧任务；验证成片时长与音轨，素材缺失明确失败。

模型相关原有测试采用隔离协议替身，不代表新做了模型效果评测。渲染测试使用合成媒体，不代表已完成人物、英文访谈或长视频语义剪辑效果评测。

## 4. 当前边界与待确认事项

- 第一阶段只允许保守的整句内部删除；缺词级对齐时，不执行半句自动语音清理。源逐字稿当前包含按字数分配的显示时间戳，不能据此宣称词级精剪准确。
- 尚未接入 VAD、强制对齐、说话人分离、主动说话人识别和智能切人；没有自动删除口头禅、重复表达或停顿。
- 尚未扩展三标题生成、关键词包装、人物标签、网络 B-roll、授权 BGM、ducking、完整技术质检和最终内容批准；按原路线在后续阶段实现。
- 现有包框可试用；正式上线仍需要四频道实际品牌素材和编辑规则。通用模板确认不等于官方视觉验收。
- 当前任务队列适用于本地单个 Bun 服务进程，不支持多实例同时消费，也不宣称分布式队列或多用户权限已经实现。
- 删除本句可能改变原意，应由编辑试听和核对；本阶段提供可恢复操作，尚无自动语义删点审查。

## 5. 用户试用清单与下一阶段

打开本地工作台 `http://localhost:5180`：

1. 新建任务检查四频道选择、频道模板推荐及封面/正文一次确认。已有项目可在品牌页补充确认。
2. 在已有片段剪辑页修改一句字幕，离开输入框后刷新检查保存；删除中间一句，检查时长与保留区间，然后撤销和重做。
3. 品牌页调整缩放/位置，保存并生成成片预览，检查人物窗口、字幕和包框；修改后重新生成，避免把旧预览当新结果。
4. 尝试批量导出，核对实际文件与所选版本。收费 ASR/模型只在主动发起相关分析时调用，此阶段底座无需新增模型密钥。

确认第一阶段后，下一步仅进入**第二阶段：保守粗剪与人工精修**，先做 VAD 和词级对齐质量检查，再逐步加入可试听、可撤销的静音及重复表达建议；低置信度、重叠发言、重要数字和否定一律保留。继续前等待用户确认。
