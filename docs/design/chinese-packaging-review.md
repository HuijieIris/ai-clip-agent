# 成片确认页与中文文字包装设计（待确认）

本文件记录已确认的设计；相关功能现已实现，交付与实测边界见 [中文包装阶段报告](../chinese-packaging-stage-report.md)。本轮不推进 VAD 等语音粗剪能力。用户当前要求优先于旧文档“默认导出原文字幕”的约定；确认后同步更新该约定。

## 页面布局

桌面宽屏采用 10% 片段列表 / 65% 中央预览 / 25% 属性面板（含间距的近似比例）。左栏最小约 144px，右栏约 320–380px，中央占剩余空间；较窄屏折叠片段栏，保证预览优先。

- 顶栏：项目名称、已保存/未保存状态、保存、批量确认与导出。
- 左栏：小缩略图、序号、两行中文标题、时长、待核对/已确认状态。删除重复的底部片段选择条。
- 中央：顶部「视频正文 / 封面」切换和画幅/缩放；主体始终为画面，不插入大型配置表单；底部播放、进度、时间、逐帧与渲染预览状态。9:16 画布高度优先，目标使用中央可用高度的 80%–90%，保持比例，不拉伸画面。
- 右栏：「标题 / 字幕 / 画面 / 品牌」四个页签。频道和封面/正文模板一次确认放在品牌页签/抽屉中；中央仅显示已绑定频道及模板小标签。
- 画面上单击标题/字幕，右栏自动选中对应文字层；支持拖动，超出模板安全区时吸附回安全区并提示。
- 页面参数示意预览和保存后的 FFmpeg 成片预览明确区分；调整后标记“预览待更新”，不把旧渲染当作新结果。

## 中文字幕规则

1. 英文及其他外文：复用已有中文译文与复核结果，按原始句子 ID 回溯；缺失才补译，不无故重跑 ASR。原声保留，不自动中文配音。
2. 中文源视频：校对已有 ASR，不再次翻译。所有新增字幕和标题以中文呈现；产品/人名等必要专名可保留，如 GPT、Azure，不为追求全汉字而误译。
3. 独立任务对照原文复核人物、术语、数字、单位、否定、条件；疑点标黄，点击可以查看原文及回听原声。文本复核不等于事实查证或原声完全正确。
4. 普通画面只显示中文；右栏字幕列表支持「中文编辑 / 原文对照」。原文不随对照开关被烧录到成片。
5. 保持源句区间总边界，按中文标点和语义断句；初始默认每行约 14–18 个中文字符、最多两行，并根据实际字体宽度与模板安全区排版。未获得词级对齐时不宣称逐词同步，子句时间为显示估算并可人工调整。
6. 中文缺失或复核失败时明确显示“待翻译/待核对”，保留已有成功结果，可单句重试；不得静默改烧英文字幕。必要疑点在批量审核中集中处理，不逐句弹窗。
7. 既有英文字幕和手工修改保留原件；首次生成中文包装新增语言层，不覆盖原文。用户改过的中文句子锁定，重新生成默认跳过。
8. 默认高亮专名/关键数字等少量有依据的词；支持选中文字高亮或取消。默认整句区间显示固定高亮，不依赖尚未接入的词级卡拉 OK 时间轴。

## 标题：一次生成三组，封面和正文配对

每条切片生成 3 组中文候选，每组包含「封面标题」和「视频内短标题」。三组建议分别偏事实信息、观点冲突、影响讨论；内容不支持时不强行制造冲突。模型输入只包含该切片真实内容、必要上下文、频道定位及可选用户要求。

右栏默认显示 3 张标题卡，卡片同时预览两种标题。点选一组后，同时应用到封面和正文；用户仍能分别修改二者。封面初始目标约 24–40 字，正文约 16–28 字，字数是排版目标，准确性优先。超长时提示缩短或调整字号，不静默删改已编辑标题。

必须保留预测/条件/人物归属，不能把推测改成事实；引号只用于真实可回溯原句，不拼造名人引语。候选保留句子依据与复核疑点，不将“有讨论潜力”当作夸大承诺。

右栏标题控件：候选选择、封面/正文分别编辑、字体、字号、颜色、字重、对齐、位置、行距、恢复默认；正文另有全片/开头若干秒/关闭。封面图片独立导出；是否作为片头插入另设开关，默认不因生成封面而改变视频时长。

## 字幕和批量交互

字幕页签包含逐句中文文本、当前播放句高亮、原文对照、单句重译/复核及样式。样式支持可用字体列表、字号、颜色、关键词强调色、描边/底色、位置、行距与断句；不可用字体明确回退提示，预览与服务器字体保持一致。

“应用到全部切片”默认只批量应用文字样式和布局，不复制同一标题或字幕内容。每条切片保留独立文本。用户手工锁定的文本/位置不被重新生成覆盖；如需覆盖，明确列出影响范围再确认。

主要流程：选片段 → 批量生成中文包装 → 中央预览、右栏集中修改 → 保存并更新成片预览 → 批量确认、导出。

生成进度分别显示翻译/复核/标题/排版，已成功结果可复用，失败可单条重试。频道切换后提示标题定位需刷新，但不自动覆盖用户已改标题。

## 确认后的实现顺序与验收

1. 页面重排：大预览、缩小片段列表、右栏分区和品牌抽屉。验收中央画面不再被表单挤到下方，封面和正文可独立查看。
2. 中文包装数据层：复用译文、保留原文/手工修改/复核状态，源时间映射不变。验收英文原声对应中文字幕，缺译文不回退英文输出。
3. 三组配对标题与文字编辑：真实调用现有模型、结构化输出和原句依据，用户修改可保存并撤销。验收三组实际可用候选、封面/正文独立文字层、批量不复制内容。
4. 排版与 FFmpeg 渲染对齐：文字位置、样式、高亮、断句、显示区间、封面导出。验收预览和实际视频一致，长中文不越安全区，修改后旧预览标记过期。
