# 二次剪辑双语字幕交付

范围：按用户确认截图，在二次剪辑中央预览区顶部、“替换画面”右侧增加「字幕语种」。保留原有三栏、包框、主题、素材和原声音轨；不推进 BGM 等后续功能。

## 行为

- 英文片段默认「中英双语」：中文在上，英文在下，英文略小；可切换「仅中文」「仅英文」。选择保存到片段，成片预览、MP4 和字幕文件沿用，不删除另一语种。
- 进入英文片段时自动准备中文字幕：优先复用已有译文和缓存，缺失才调用既有文本模型翻译及复核。此次准备只做字幕，不重新生成或替换标题。失败明确提示、可重试，不伪造中文。
- 左侧原文稿和源字幕仍保留原件，剪辑区间映射、撤销/重做继续工作。仅英文模式直接使用当前保留区间的原文，不依赖中文生成是否成功。
- 取消字幕黑色背景、阴影和背景模糊；白字加纯黑、圆角连接描边。实现约定为 **1080 宽输出 15px**，其他宽度等比缩放。这是本项目的可复现实现口径，不宣称等同剪映内部“15”的私有参数。
- 页面按视频显示宽度缩放字和描边；服务器实际预览、导出使用透明 PNG 图层。双语英文缩小以适配区域，无法排入时明确报错；失败图层不作为成功缓存。
- 复用原时间轴，不改变音轨、不做中文配音。源视频自己烧录的文字不会被移除。

## 验证

- 全量自动测试：69 通过、0 失败，247 次断言。
- 新增测试：英文默认双语、中文源推断、三种模式不丢数据、时间映射、透明背景、上中文下英文、黑描边与分辨率缩放。
- API 测试验证语种持久化、自动字幕准备不生成标题、描边设置保存。
- 真实 FFmpeg 测试用英文原文＋中文字幕导出，验证产物时长与音轨；既有剪辑/字幕/包框测试继续通过。
- 后端 TypeScript、前端 TypeScript 和生产构建通过。
- 浏览器自动连接此前不可用，本轮不宣称已完成实际页面点击、截图和视觉验收。

## 试用

刷新英文片段的「二次剪辑」页，等待中文字幕准备完成；在“替换画面”右侧切换字幕语种。检查无黑底、中文上英文下，进入成片确认生成实际预览后核对导出。

如果翻译未就绪，可查看具体错误重试；仅英文模式可独立使用。字幕分屏时间仍是原句区间内估算，并非词级强制对齐。
