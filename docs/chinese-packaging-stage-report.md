# 中文包装与成片确认页交付报告

日期：2026-11-15。范围：用户确认的功能布局、中文字幕、三组配对标题及文字包装。没有推进 VAD、自动删口头禅、主动说话人切换或素材/BGM推荐。

## 已实现

- 成片确认页改为窄片段列表、大画面预览、右侧「标题 / 字幕 / 画面 / 品牌」。宽屏采用约 10:65:25 的弹性布局，并对较窄屏折叠片段栏。频道、模板确认移到右栏，删除重复的底部片段选择条。
- 继续使用现有 CSS 主题变量、原项目 Logo/封面/正文包框和媒体文件。没有将效果图中的人物或品牌装饰写入产品。现有项目依然使用已绑定模板快照。
- 独立 `Clip.packaging` 保存中文句子、原句、复核疑点、手工锁、配对标题和样式。原 ASR、原文字幕、现有 EditPlan、替换素材和模板快照保留。
- 优先复用原高光流程的译文；缺失的才分批翻译并独立复核。中文源字幕增加文本错字/断句校对任务。原声继续保留，不做中文配音。文本复核不代表已核实原声听写或客观事实。
- 标题真实调用已有千问兼容接口，每条返回三组「封面标题 / 视频内标题」，含角度与原句编号依据，校验三组数量、差异和来源。点击配对应用，也支持分别修改。手工文本锁定后重新生成不覆盖。
- 正文标题独立渲染，可选全片 / 仅开头 / 关闭。封面标题独立保存和导出；封面插入视频开头的原有设置继续可用。
- 字幕仅显示中文，原文在右栏折叠对照。支持手工换行分屏、选词高亮、取消高亮、单句重译与复核、疑点核对；默认对少量关键术语/数字强调。必要专名如 GPT、Azure 可保留，不强行误译。
- 字体由服务器提供实际可用列表，当前环境有中文黑体、宋体；字号、颜色、强调色、字重、对齐、行距、位置、宽度、描边/底色可调。画面文字可选中拖动，也可用右栏滑杆调整。
- 文字示意预览和导出使用同一套服务器 PNG 栅格排版，避免浏览器与 FFmpeg 使用不同字体布局。改变设置后旧成片预览显示待更新。正文标题/字幕/封面分别为独立图层。
- 原有视频构图、构图批量应用、视频抽帧、上传封面、首屏封面时长、批量导出保留。包装编辑进入现有快照撤销/重做；过期 revision 返回 409。文字样式批量应用使用事务，不复制各片文本。
- 缺中文字幕或源句变化时不回退英文烧录；翻译疑点可在预览中核对，正式导出前集中确认。模型失败显示真实错误，保留旧结果和翻译缓存。后台任务可查进度，服务重启中断的任务明确可重试。

## 已知边界

- 字幕分屏的时间分配仍是原句区间内的显示估算，尚无词级强制对齐，不能当作词级精剪或卡拉 OK 高亮。
- 字幕最多两行；字号/文字区域过大或移出画布时明确提示，不静默裁掉中文。改变模板后保留现有文本和位置供调整，不自动覆盖手工排版。
- 标题附带原句依据，但最终新闻表述仍需编辑审核；生成三组不代表已全面查证事实。
- 不移除源视频本身已经烧录的英文文字，只控制本系统新增的字幕与标题。
- 任务队列服务于本地单进程；不宣称多实例、多人协作或分布式任务系统已完成。

## 试用

1. 在原项目进入「成片确认」，右侧标题页点「生成当前片段中文包装」或「批量生成全部」。
2. 选择三组标题之一，切换中央封面/正文分别调整；字幕页可对照原文、回听和修改。
3. 保存后生成实际成片预览，再批量导出。若还有字幕疑点，在字幕页集中核对。
4. 本次验收后再确认下一阶段；不自动进入 VAD/说话人分离开发。
